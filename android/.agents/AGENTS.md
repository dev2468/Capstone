# Response Formatting Rules

- Always respond in clean Markdown
- Use headers (##) for sections
- Use bullet points and numbered lists where appropriate  
- Use **bold** for important terms
- Use code blocks with language tags for any code
- For data comparisons always use tables
- When showing file contents, use appropriate code blocks
- For step by step instructions use numbered lists
- Keep paragraphs short — max 3 lines each
- When you have numeric data, suggest if a chart would help and describe what type
